# Полная рыночная стоимость в карточке облигации

## Цель

В карточке облигации показывать текущую рыночную стоимость позиции с учётом накопленного купонного дохода (НКД), так же как в модальном окне просмотра облигации.

## Поведение

- Для открытой позиции итоговое значение равно рыночной стоимости без НКД плюс текущий НКД.
- Карточка показывает только итоговое значение без отдельной разбивки на составляющие.
- Если НКД недоступен, карточка показывает рыночную стоимость без НКД.
- Если рыночная стоимость недоступна, карточка показывает `—`.
- Для закрытой позиции НКД не прибавляется, что соответствует поведению модального окна.
- Текст тултипа: «Текущая рыночная стоимость + НКД».
- Сортировка портфеля не меняется: задача затрагивает только отображение значения в карточке.

## Архитектура

Расчёт итоговой стоимости остаётся внутри слайса `PortfolioPage`, ближайшего владельца обоих представлений. Общая чистая функция складывает денежные строки без потери точности и возвращает значение для отображения. Карточка и модальное окно используют одну функцию, чтобы их fallback-поведение оставалось одинаковым.

## Проверка

Компонентный тест подтверждает, что открытая позиция в карточке показывает сумму рыночной стоимости и НКД без разбивки, а тултип содержит согласованный текст. Существующая проверка модального окна подтверждает, что оба представления остаются согласованными. E2E-проверка обновляется под новое значение и новый текст тултипа.
