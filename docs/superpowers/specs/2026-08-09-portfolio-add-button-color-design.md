# Одинаковый фон кнопки добавления облигации

## Цель

Кнопка «Добавить облигацию» на странице портфеля должна иметь одинаковый зелёный фон в светлой и тёмной темах.

## Решение

- Изменение локализуется в `PortfolioPage.module.scss` и применяется только к `addButton`.
- Основной фон в обеих темах: `#2f805f` — текущее значение `--green` тёмной темы.
- Фон при наведении в обеих темах: `#236649` — текущее значение `--green-dark` тёмной темы.
- Цвет текста, иконка, фокус, размеры и поведение кнопки остаются без изменений.
- Глобальные переменные темы и остальные primary-кнопки не меняются.

## Проверка

- Линтер и TypeScript.
- Component-тесты страницы портфеля.
- Production-сборка frontend.
- Проверка отсутствия изменений глобальных theme-токенов.
