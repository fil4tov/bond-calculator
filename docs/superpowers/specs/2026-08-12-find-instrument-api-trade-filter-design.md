# Фильтр доступных для API-торговли облигаций

## Цель

Ограничить результаты поиска облигаций инструментами, доступными для торговли через API T‑Invest.

## Изменение

В существующем вызове `client.instruments.find_instrument(...)` внутри
`TInvestGateway.search_bonds` передавать `api_trade_available_flag=True` вместе с
исходной строкой поиска и `InstrumentType.INSTRUMENT_TYPE_BOND`.

Дополнительная фильтрация ответа на стороне приложения не требуется. Остальные
вызовы T‑Invest, включая `BondBy` и получение последних цен, не изменяются.

## Проверка

Unit-тест fake-клиента должен принимать параметр `api_trade_available_flag` и
проверять, что gateway всегда передаёт значение `True`. Изменение выполняется по
TDD: сначала тест должен упасть из-за отсутствующего аргумента, затем пройти после
минимальной правки production-кода.
