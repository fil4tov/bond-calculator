# Годовая купонная доходность облигации в портфеле

## Цель

Привести новый показатель общей купонной доходности в модалке облигации к тому же смыслу, который используется в калькуляторе: показывать доходность, приведённую к полному году, а не долю купонов, попадающих в оставшуюся часть текущего календарного года.

## Расчёт

Годовая купонная доходность рассчитывается по формуле:

```text
ближайший известный купон на одну облигацию
× количество выплат в год
× текущее количество облигаций
÷ себестоимость оставшейся позиции
× 100%
```

Для облигации со значениями 11,67 ₽, 12 выплат в год, 200 бумаг и себестоимостью 199 957 ₽ результат равен 14,01%.

Ближайший известный купон используется как актуальная ставка. Поэтому для плавающего купона показатель является годовым эквивалентом текущей известной выплаты и пересчитывается при смене ближайшего купона.

Результат округляется `ROUND_HALF_UP` до четырёх знаков после запятой на backend. При закрытой позиции, нулевой себестоимости, отсутствии ближайшего положительного купона или нулевой частоте выплат API возвращает `null`, а интерфейс показывает прочерк.

## Интерфейс и контракт

- Ячейка называется «Годовая купонная доходность» без календарного года.
- Тултип: «Показывает, какую купонную доходность принесла бы облигация за полный год, если размер ближайшего купона не изменится».
- Новое ещё не зафиксированное поле `calendar_year_total_coupon_yield_percent` заменяется на `annual_coupon_yield_percent`; frontend-модель использует `annualCouponYieldPercent`.
- Показатели «Ожидаемый купонный доход за {год}» и «Доходность отдельных купонов за {год}» сохраняют текущие календарные формулы и названия.
- Маршруты API и структура базы данных не меняются.

## Проверка

- Backend: совпадение с формулой калькулятора, округление, частичная продажа, отсутствие купона, нулевая частота выплат и закрытая позиция.
- API/frontend: адаптация нового поля, название, тултип, формат процента и прочерк для `null`.
- Component/E2E: пример из интерфейса отображает 14,01%; остальные календарные показатели остаются без изменений.
