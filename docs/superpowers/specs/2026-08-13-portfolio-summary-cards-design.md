# Сводные карточки портфеля облигаций

## Цель

Над сортировкой и списком облигаций разместить две полноширинные информационные карточки: верхнюю со сводкой открытых позиций и нижнюю с купонными показателями текущего календарного года. Существующую маленькую карточку ожидаемого купонного дохода справа от сортировки удалить.

## Карточка облигаций

- Слитная строка из четырёх секций, разделённых линиями без промежутков.
- Главная секция «Рыночная стоимость с НКД» использует фиксированный градиент `linear-gradient(135deg, #174f39 0%, #287455 58%, #2f805f 100%)` и показывает сумму текущей стоимости открытых позиций с доступным НКД.
- «Открытых выпусков» — количество элементов с `positionStatus === 'open'`.
- «Вложено» — сумма `positionCostBasis` открытых позиций.
- «За всё время» — рыночная стоимость с НКД минус вложенная сумма; положительное, отрицательное и нулевое значения имеют разные смысловые цвета. Тултип: «Разница текущей рыночной стоимости с НКД относительно вложенной суммы».
- Если хотя бы у одного открытого выпуска отсутствует рыночная стоимость, общая стоимость и результат показываются как `—` с поясняющим тултипом. Недоступный НКД сохраняет уже согласованный fallback к стоимости без НКД.

## Карточка купонов

- Верхняя часть состоит из трёх равных слитных секций: «Получено купонами за {year} год», «Всего ожидается за {year} год», «Выплаты в {month}».
- Полученная сумма охватывает купоны с начала текущего года по текущую дату. Годовая ожидаемая сумма включает все известные купоны текущего года. Месячная сумма включает весь текущий календарный месяц; при отсутствии выплат показывается `0 ₽`.
- По нижнему краю проходит прогресс высотой `34px`, совпадающий с `couponTrack` карточки облигации: фон `#eef5f1`, заполнение `linear-gradient(90deg, #dfece5 0%, var(--lime) 100%)`.
- Заполнение равно `received / expected`, ограничено диапазоном 0–100%; при нулевой ожидаемой сумме — 0%.
- Внутри прогресса только слева отображается `{received} / {expected}` без процента, остатка и текста справа. Прогресс имеет доступные `role`, `aria-valuenow` и `aria-valuetext`.
- Купонные агрегаты учитывают все сохранённые выпуски, включая закрытые, чтобы полученный в текущем году доход не исчезал после продажи позиции.

## Адаптивность и состояния

- Обе карточки показываются только после успешной загрузки непустого портфеля и сохраняются во время фонового refetch.
- На широком экране каждая карточка остаётся одной строкой. На планшете главная секция занимает полную ширину, вторичные показатели остаются компактной строкой. На телефоне секции складываются вертикально внутри общей рамки.
- Светлая и тёмная темы сохраняются; основной зелёный градиент неизменен в обеих темах. Глобальный `prefers-reduced-motion` отключает анимацию прогресса.

## Данные

Backend добавляет в существующий элемент портфеля два вычисляемых строковых поля без миграции базы: `calendar_year_paid_coupon_income` и `calendar_month_coupon_income`. Frontend адаптирует их в `calendarYearPaidCouponIncome` и `calendarMonthCouponIncome`.

## Проверка

Backend-тесты проверяют границы года и месяца. Frontend unit/component-тесты проверяют точное денежное агрегирование, неизвестную рыночную стоимость, формулы результата и прогресса, тексты, удаление старой мини-сводки и высоту прогресса через визуальный/E2E контракт. Адаптивный E2E подтверждает отсутствие горизонтального переполнения.
