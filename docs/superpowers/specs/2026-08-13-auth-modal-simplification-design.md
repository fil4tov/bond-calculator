# Упрощение модалки авторизации

## Цель

Сделать модалку входа и регистрации компактнее: убрать второстепенный текст, уточнить заголовок и визуально отделить поля от основного действия.

## Решение

- Удалить надпись «Личный кабинет» над заголовком.
- Использовать единый заголовок «Авторизация» в режимах входа и регистрации.
- Сохранить существующий переключатель «Вход» / «Регистрация» и его клавиатурное поведение.
- Удалить поясняющий текст под переключателем в обоих режимах.
- Заменить placeholder поля логина на «Логин».
- Оставить placeholder поля пароля без изменений.
- Поместить кнопку отправки в локальный блок действий и отделить его от полей тонкой горизонтальной границей с отступами.
- Использовать одинаковый разделитель для кнопок «Войти» и «Создать аккаунт», чтобы компоновка не менялась при переключении режима.
- Сохранить текущие темы, адаптивность, сообщения валидации и состояние отправки.

## Архитектура

Изменения принадлежат локальному компоненту `AuthModal` внутри `widgets/SiteHeader`. Общие компоненты `Modal`, `TextField` и `Button` менять не требуется. Новые публичные API и зависимости не добавляются.

## Проверка

- Component-тест фиксирует заголовок, отсутствие удалённого текста, новые и сохранённые placeholder и наличие разделителя перед действием.
- Существующие сценарии регистрации, входа, валидации и клавиатурного переключения продолжают работать.
- Выполняются lint, typecheck и релевантные component-тесты frontend.
