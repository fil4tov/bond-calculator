# Интерактивный hover карточки облигации

## Поведение

- Эффект работает только над основной частью карточки `.main`; правая секция с кнопкой `•••` не меняется.
- Фон основной части по умолчанию и за пределами локального пятна не меняется.
- В светлой теме возле курсора появляется едва заметное затемнение, в тёмной — едва заметное осветление.
- Пятно плавно затухает от центра к полностью прозрачному краю большого радиуса.
- При уходе курсора с основной части маска плавно исчезает.
- На устройствах без точного указателя и при `prefers-reduced-motion: reduce` эффект отключён.

## Реализация

- `pointermove` вычисляет координаты относительно `.main` и записывает их в `--hover-x` и `--hover-y` непосредственно в inline style элемента без React state.
- Псевдоэлемент `.main::before` рисует `radial-gradient` радиусом `360px`: тонировка составляет `3%` в светлой теме и `4%` в тёмной в центре, затем плавно затухает до полной прозрачности на краю. `pointer-events: none` сохраняет кликабельность и существующий focus outline.
- Тема задаёт только цвет тонировки через CSS: полупрозрачный чёрный для светлой и белый для тёмной.
- Текущий однотонный hover у невидимой кнопки деталей удаляется, чтобы он не перекрывал новый эффект.

## Проверка

- Component-тест проверяет координаты CSS-переменных относительно основной области и отсутствие этих переменных на кнопке меню.
- Lint, typecheck, unit-тесты и production build остаются зелёными.
