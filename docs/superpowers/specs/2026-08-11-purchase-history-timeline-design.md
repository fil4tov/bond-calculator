# История покупок в модалке облигации

## Цель

После блока ближайшего купона показать все покупки выбранной облигации вертикальным таймлайном. Новые покупки располагаются сверху; каждая запись показывает сумму и количество слева, дату покупки справа.

## Данные и поведение

- Существующий `BondCard` получает массив `purchases` с `id`, `amount_spent`, `quantity` и `purchase_date`.
- Backend уже загружает покупки для расчётов, поэтому история формируется без отдельного запроса.
- Покупки сортируются по `purchase_date` и `created_at` по убыванию, затем по `id` для стабильности.
- Ответы создания облигации и добавления покупки содержат тот же массив, поэтому React Query-кэш остаётся самодостаточным.

## Визуальное решение

- Под купонным блоком размещается заголовок «История покупок» и счётчик с корректной русской формой слова «покупка».
- Вертикальная линия и круглые маркеры связывают записи в хронологию.
- Сумма — главный акцент слева, количество располагается под ней; дата выровнена справа.
- На узком экране дата сохраняет правое выравнивание и переносится только при нехватке ширины.
- Используются существующие цвета темы, границы и типографика модалки; список не получает самостоятельный скролл.

## Проверка

- Backend API-тест проверяет поля и сортировку истории.
- Frontend adapter-тест проверяет преобразование snake_case в camelCase.
- Component-тест проверяет заголовок, счётчик, порядок записей и их основные значения.
- E2E проверяет появление новой покупки в истории после добавления на desktop и mobile.
